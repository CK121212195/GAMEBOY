# ₿ SATOSHI CATCHER — クリプトUFOキャッチャー

ビットコインやクリプトのぬいぐるみを狙う、ブラウザで遊べるUFOキャッチャーです。
ライブラリ不要の素の HTML / CSS / JavaScript（Canvas）だけで動きます。

## 🎮 あそびかた
- **COIN** で 100 sats 投入 → **◀ ▶**（キーボードは ← → / A D）でアームを動かす → **DROP**（Space / ↓）
- 画面をドラッグして狙い、タップでDROPもOK（スマホ対応）
- 取れたぬいぐるみは **HODLバッグ** へ。相場（ティッカー）は常に動き、ニュースで急騰・急落します。ガチホか利確かはあなた次第
- ハズレるたびに **HODLゲージ** が溜まり、満タン（7）で次は確定キャッチ
- 21プレイごとに **ハルビング** → 3プレイの間 **BULL RUN**（アーム強化）
- 連続GETでストリークボーナス、毎日ログインでデイリーボーナス、残高不足時は **Faucet**
- 全11種の **図鑑** コンプを目指そう（ラグプル絨毯もあるよ）

進行状況はブラウザの localStorage に保存されます。

## 📁 構成
- `index.html` — 画面
- `style.css` — ネオン筐体デザイン
- `game.js` — 物理演算（ポジションベース）、アーム制御、マーケット、UI

## ⚠️ 注意
ゲーム内の sats は架空のポイントです。実際のお金・暗号資産は使いません／もらえません。ゲーム内ニュースはすべてフィクションです。
